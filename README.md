# 足球赛事

今日足球赛程小组件（独立版）：时间跟手机时区，不依赖任何私人服务器。默认关注 10 间球会，国家队需自行添加。

## 一键导入

在 iPhone / iPad 上用 Safari 打开下面的链接，即可唤起 Scripting 导入：

```
https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2Fronlzw%2Ffootball-standalone%2Fmain%2Ffootball-standalone.zip%22%5D
```

## 功能

- 今日比赛全部显示，未来场次逐日补足最近 8 场
- 11 个联赛、204 间球会自由关注；全部 221 支国家队，按 FIFA 排名顺序排列并标注真实排名，国家队前 10 / 20 / 30 / 40 / 50 一键添加
- 通过联赛、球队两栏菜单添加关注，点标签上的 × 删除；恢复默认只保留最初 10 间球会，不带国家队
- 小组件与设置页跟随手机语言（简体、香港繁体、台湾繁体、英文）
- 点击直达：点标题打开赛事应用，点任意一场比赛打开该场比赛详情页，点底部刷新赛程，不会跳转
- 大尺寸最多同时显示 8 场比赛，中尺寸 4 场，小尺寸 1 场
- 自动更新：组件每天检查一次，有新版本时自动更新；同版本号的小幅修正需手动重新导入一次
- 本组件不收集、不上传任何个人信息
