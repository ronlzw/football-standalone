# 足球赛事

足球赛事小组件：默认关注 10 间球会 + FIFA 前 40 国家队，数据直连 FotMob，时间跟手机时区，不依赖任何私人服务器。

## 一键导入

在 iPhone / iPad 上用 Safari 打开下面的链接，即可唤起 Scripting 导入：

```
https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2Fronlzw%2Ffootball-standalone%2Fmain%2Ffootball-standalone.zip%22%5D
```

## 说明

- 每次刷新直接从 FotMob 获取今日及未来赛程，补足最近 8 场
- 可在组件内编辑关注球队（点标签上的 × 删除，两级联赛球队菜单添加），国家队（FIFA 前 40）维持不变
- 自动更新：新版本发布后，组件每天检查一次并自动更新，无需手动重新导入
- 本组件不收集、不上传任何个人信息
